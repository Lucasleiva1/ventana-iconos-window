# Desktop Organizer v1.1.4

## Mejoras

- El Dock ofrece dos opciones cuando se llena: conservar las flechas o ajustar iconos, celdas y espacios. En el modo de ajuste, los iconos se reducen hasta 20 px y luego vuelven a aparecer las flechas para mantener todos los accesos disponibles.
- Los Cajones muestran una miniatura real de los archivos de imagen en lugar del icono genérico, cuando Windows puede generarla. Las imágenes ya agregadas reciben una caché de miniaturas nueva.
- El nombre debajo de cada elemento se lee mejor y el Cajón abierto tiene altura suficiente para mostrar una miniatura grande junto con dos líneas de nombre.

## Actualización

Actualización automática firmada desde la versión instalada anterior. Los Cajones, el Dock y los archivos del usuario se conservan.
